Building a Decoupled, Custom Image Classifier

A Production-Grade Reinterpretation of Google's Teachable Machine

  • Platform: Streamlit (Frontend Dashboard) + FastAPI (Backend ML Server)
  • ML Pipeline: PyTorch MobileNetV3 Feature Extractor + Scikit-Learn Logistic Regression Classifier
  • Deployment: Multi-container Docker & Docker Compose setup with persistent volumes
Speaker Notes
"Welcome, everyone. Today, I am excited to present the Teachable Machine Pro project. In this presentation, we will walk through how we transformed a prototype image classification workflow into a decoupled, production-grade client-server application. We will look at our technical architecture, our machine learning pipeline, our APIs, the frontend design system, error handling strategies, and how we packaged everything into Docker containers for seamless deployment."
